# 💻 Lab Management System (Java EE)

## 📌 Overview
At university, we used to sign into the computer lab using pen and paper. This process was time-consuming and inefficient. So, along with two of my amazing friends, we decided to create a digital lab sign-in system to improve accuracy, save time, and eliminate the need for manual logs.

## ⚙️ Technologies Used
- **Backend:** Java EE (Servlets, JSP, EJBs)
- **Frontend:** JSP (Java Server Pages)
- **Database:** MySQL
- **Web Server:** Apache Tomcat

## 🚀 Features
- Digital sign-in for lab users
- Stores lab usage records in a database
- Admin interface for monitoring lab activity
- Secure and structured architecture using Java EE standards

## 🔒 Upcoming Improvements
- 🔁 **Migration to Spring Boot** for faster development and better maintainability
- 🔐 **Role-based Authentication** (e.g., students, lab admins)
- 📊 **Analytics Dashboard** (e.g., usage patterns, busiest lab hours)
- 📧 **Notifications/Logs** for better lab supervision

## 📂 How to Run the Project
1. Clone the repository
2. Import it into an IDE that supports Java EE (e.g., Eclipse, IntelliJ)
3. Set up a MySQL database using the provided schema
4. Configure the server (Apache Tomcat recommended)
5. Deploy and run
